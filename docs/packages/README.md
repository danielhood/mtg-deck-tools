# Package documentation (monorepo)

Application code lives in package directories; **shared** product, architecture, specs, roadmap, and history stay in [`docs/`](../README.md).

| Package | Doc stub | Code (today / planned) |
| --- | --- | --- |
| CLI | [cli/README.md](cli/README.md) | `src/mtg_deck_tools/` |
