# Dependency audit reports (D0.5)

Generated by:

```bash
mtg-deck-tools import   # requires oracle bulk in resources/scryfall/
mtg-deck-tools dependency-audit
```

Default output directory: `resources/dependency/reports/`.

## Artifacts

| File | Contents |
| --- | --- |
| `dependency-audit-summary.json` | Full audit payload |
| `dependency-pattern-hits.json` | Per-pattern hit counts + example card names |
| `dependency-profile-summary.json` | Energy / aura / elf / artifact role totals globally and by color identity |
| `tutor-predicates.csv` | Clustered `search_library` payloads with frequencies |
| `dependency-review-queue.json` | Unmatched “search your library” lines and low-confidence atoms |

Reports are **not** committed by default (regenerate after each bulk import). Maintainer may commit a snapshot when calibrating `dependency-profiles.yaml`.

## Custom output path

```bash
mtg-deck-tools dependency-audit --out /path/to/reports
```
